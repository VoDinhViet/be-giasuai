# Learning Analytics

## Muc dich

Module `learning-analytics` so huu cac du lieu tong hop ve tien do, hieu qua hoc tap, diem yeu va canh bao. Module nay lay tin hieu tu learning delivery, assessments, AI va classroom.

## Pham vi chuc nang

- Dashboard tien do hoc tap cho Student.
- Thong ke gio hoc, so module da hoan thanh, bieu do tien bo theo thoi gian.
- Lich su hoc tap chi tiet.
- Tracking diem yeu do AI gan the va luu DB.
- Bao cao diem yeu ca nhan, lop va tong hop module kho.
- Teacher nhan canh bao khi hoc sinh bi ket o mot kien thuc.
- Admin dem/tong hop nguoi dung, khoa hoc va module kho.

## Vai tro

| Vai tro | Nhu cau |
| --- | --- |
| Student | Xem dashboard, lich su hoc, diem yeu ca nhan. |
| Teacher | Xem tien do hoc sinh, diem manh/yeu, thoi gian hoc trung binh va canh bao bi ket. |
| Admin | Xem so lieu he thong, module kho va du lieu cai tien noi dung. |

## Ngoai pham vi

- Nguon progress goc nam trong `learning-delivery`.
- Nguon diem/feedback nam trong `assessments-grading`.
- Class membership nam trong `classroom-management`.
