# User Profiles

## Muc dich

Module `user-profiles` so huu thong tin hien thi va ho so ca nhan cua nguoi dung sau khi da co identity hop le. Module nay giup Student/Teacher cap nhat thong tin co ban va giup Admin xem ho so, hoat dong co ban cua nguoi dung.

## Pham vi chuc nang

- Xem thong tin ca nhan.
- Cap nhat ten va thong tin co ban.
- Quan ly anh dai dien.
- Admin xem ho so nguoi dung va hoat dong co ban.
- Ket noi voi file upload neu can luu avatar.

## Vai tro

| Vai tro | Nhu cau |
| --- | --- |
| Student | Them/sua ten, anh dai dien va thong tin ca nhan co ban. |
| Teacher | Quan ly thong tin ca nhan phuc vu lop hoc va noi dung giang day. |
| Admin | Xem ho so va hoat dong co ban cua nguoi dung. |

## Ngoai pham vi

- Dang ky, dang nhap, khoa tai khoan nam trong `identity-access`.
- Tien do hoc tap va diem yeu nam trong `learning-analytics`.
- Goi dich vu nam trong `service-packages`.
