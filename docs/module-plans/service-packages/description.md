# Service Packages

## Muc dich

Module `service-packages` so huu goi dich vu `casual/plus/pro`, quyen loi theo goi va quota/limit. Theo yeu cau, module nay lam sau cung va khong chan cac module cot loi.

## Pham vi chuc nang

- Dinh nghia cac goi `casual`, `plus`, `pro` cho Student.
- Dinh nghia cac goi `casual`, `plus`, `pro` cho Teacher.
- Gan goi cho nguoi dung.
- Gioi han/quota theo goi, dac biet quota tao de/AI.
- Admin quan ly cap quyen/goi.

## Vai tro

| Vai tro | Nhu cau |
| --- | --- |
| Student | Co cap goi rieng de mo quyen loi sau nay. |
| Teacher | Co cap goi rieng de mo quyen loi day hoc/AI sau nay. |
| Admin | Quan ly cap goi, quyen loi va quota. |

## Nguyen tac lam sau

- Khong chen package check vao `identity-access`, `learning-delivery`, `classroom-management` hoac `ai-personalization` trong giai doan dau.
- Cac module AI co the ghi log usage truoc, den giai doan nay moi ap quota.
- Neu can placeholder, chi luu thong tin goi mac dinh, khong lam thay doi hanh vi API cot loi.
