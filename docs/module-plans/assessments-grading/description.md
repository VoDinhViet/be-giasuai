# Assessments Grading

## Muc dich

Module `assessments-grading` so huu bai test, bai tap, ket qua lam bai, cham diem va giai thich loi sai. Day la nguon diem cho `learning-delivery` va nguon tin hieu cho `learning-analytics`.

## Pham vi chuc nang

- Test dau vao de phan loai nang luc.
- Ngan hang de test dau vao.
- Bai tap trong noi dung hoc.
- Cham diem tu dong/AI.
- Giai thich loi sai cho Student.
- Teacher xem AI cham diem tu luan va bai tap tuong tac.
- Admin giam sat do chinh xac logic cham diem AI.

## Vai tro

| Vai tro | Nhu cau |
| --- | --- |
| Student | Lam test dau vao, lam bai tap, nhan phan hoi/giai thich loi sai. |
| Teacher | Giam sat ket qua test, xem cham diem tu luan va danh gia bai tap tuong tac. |
| Admin | Quan ly ngan hang de, giam sat chat luong/chinh xac cua logic cham diem. |

## Ngoai pham vi

- Sinh lo trinh sau test nam trong `ai-personalization`.
- Mo khoa module theo diem nam trong `learning-delivery`.
- Tracking diem yeu tong hop nam trong `learning-analytics`.
