# Course Content

## Muc dich

Module `course-content` so huu noi dung hoc tap cot loi: khoa hoc, module/section, bai hoc, noi dung ly thuyet, simulator, bai tap gan voi bai hoc, tim kiem va duyet noi dung.

## Pham vi chuc nang

- Tim kiem khoa hoc, bai hoc va noi dung hoc tap.
- Doc ly thuyet, tuong tac simulator, xem bai tap trong module.
- Quan ly khoa hoc, section/module, lesson, lesson part.
- Teacher co the tim kiem khoa hoc/bai hoc, lop hoc/hoc sinh lien quan den day hoc.
- Admin duyet chat luong noi dung giao vien tu soan.

## Vai tro

| Vai tro | Nhu cau |
| --- | --- |
| Student | Tim khoa hoc, vao module, doc ly thuyet, tuong tac simulator, lam bai tap. |
| Teacher | Tim khoa hoc/bai hoc, tim lop/hoc sinh, soan cau hoi nhanh tu noi dung ly thuyet. |
| Admin | Tim kiem toan he thong va duyet chat luong noi dung tu soan. |

## Ngoai pham vi

- Diem qua bai va mo khoa module tiep theo nam trong `learning-delivery`.
- AI soan cau hoi/giao an nam trong `ai-personalization`.
- Cham diem nam trong `assessments-grading`.
