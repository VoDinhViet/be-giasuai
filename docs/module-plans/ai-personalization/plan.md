# AI Personalization Plan

## Muc tieu

Tao lop AI co the dua vao noi dung, ket qua assessment va diem yeu de de xuat lo trinh, ho tro chat va tao bai luyen tap ma khong lam phu thuoc vao goi dich vu trong giai doan dau.

## Ke hoach backend

- Tao service AI orchestration rieng, tach prompt/context building khoi controller.
- Lo trinh AI can luu duoc ban goc, ban da can thiep va ly do thay doi.
- AI Tutor can ho tro 2 context: general va lesson context.
- Bai tu luyen AI can sinh theo weak tags va luu ket qua de Student lam lai.
- Teacher authoring dung AI de goi y, nhung noi dung duoc duyet o `course-content` neu public.

## API/module de xuat

- `learning-paths`: generate path, get current path, update personal/class path, restore default.
- `ai-tutor`: chat general, chat with lesson context, conversation history hook.
- `ai-practice`: generate practice from weak tags, list generated practices.
- `teacher-ai-tools`: generate lesson plan/question suggestions.

## Data concept

- Learning path: owner type, owner id, generated by, status, source assessment/progress.
- Learning path item: course/lesson/module id, order, required flag, reason.
- Conversation: user id, context type, context id, messages summary.
- AI generation log: provider/model, prompt purpose, token/cost metadata, output reference.

## RBAC

- Student: xem/can thiep lo trinh ca nhan, chat AI, tao bai tu luyen cua minh.
- Teacher: tao/dieu chinh lo trinh lop, dung AI tools cho lop/noi dung minh phu trach.
- Admin: cau hinh algorithm/prompt policy va khoi phuc default.

## Verification

- Tests generate path tu placement/progress input.
- Tests Student chi sua lo trinh ca nhan cua minh.
- Tests Teacher chi sua lo trinh lop minh quan ly.
- Tests chat lesson context khong dung lesson khong ton tai.
- Tests AI generation log duoc tao khi goi AI.
