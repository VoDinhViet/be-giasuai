# Platform Admin

## Muc dich

Module `platform-admin` tong hop cac chuc nang quan tri he thong khong thuoc rieng mot domain hoc tap: dashboard he thong, cau hinh mac dinh, chi phi API, lich su hoi thoai, ticket, bao tri va tranh chap.

## Pham vi chuc nang

- Dashboard tong quan cho Admin.
- Cau hinh mac dinh he thong, vi du nguong diem mac dinh va algorithm/prompt policy.
- Quan ly chi phi API va lich su hoi thoai AI.
- Xu ly khieu nai/tranh chap Student - Teacher.
- Phan hoi ticket va bao tri he thong.
- Tim kiem/toan quyen quan tri co tinh cross-module khi can.

## Vai tro

| Vai tro | Nhu cau |
| --- | --- |
| Admin | Quan sat he thong, cau hinh rule mac dinh, theo doi chi phi, xu ly ticket/tranh chap. |
| Student | Tao phan hoi/ticket hoac khieu nai khi can. |
| Teacher | Tao phan hoi/ticket hoac tham gia xu ly tranh chap khi lien quan. |

## Ngoai pham vi

- Quan ly tai khoan chi tiet nam trong `identity-access` va `user-profiles`.
- Goi dich vu/quota nam trong `service-packages`.
- Noi dung hoc tap va lop hoc nam trong cac module domain tuong ung.
